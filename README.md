# Dignity Amenaghawon - Personal Website

Professional platform documenting the leadership journey, policy contributions, and public service of Dignity Amenaghawon.

## About
Dignity Airhuoyuwa Amenaghawon is a Nigerian policy analyst, youth advocate, and the Founder of the Dignified Future Initiative (DFI).

## Tech Stack
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **Hosting:** [Cloudflare Pages](https://pages.cloudflare.com/)

## Local Development

1. Clone the repository:
   
   git clone https://github.com/famenaghawon/dignity-amenaghawon.git
   cd dignity-amenaghawon

2. Install dependencies:
 
   npm install
  
3. Start the development server:
  
   npm run dev
   
4. Open http://localhost:4321 in your browser.

Deployment

This site is automatically deployed to Cloudflare Pages via GitHub. Any push to the main branch triggers a new build.
